**Цель**: изучить принципы работы CSS Grid и научиться применять его для построения двумерных композиций, размещения элементов, создания вложенных сеток, адаптивных интерфейсов.

## Изучить

Изучите принципы работы Grid и его свойства:

- grid-контейнер, grid-элементы;
- линии, треки, ячейки, области;
- формирование явной (grid-template-columns и grid-template-rows) и неявной (grid-auto-rows и grid-auto-columns) структуры grid;
- управление размерами элементов;
- шаблон RAM (repeat(), minmax(), auto-fit и auto-fill);
- выравнивание элементов (justify- align- place- и -items -content -self);
- порядок элементов;
- различные способы расположения элементов в сетке, span и размещение элемента на нескольких ячейках.

## Сделать

В существующий документ `index.html` в футер добавьте ссылку на документ `grid.html`.

Во всей лабораторной работе нельзя использовать CSS-свойство position. Размещение, выравнивание и наложение элементов необходимо выполнять с помощью возможностей CSS Grid.

Каждый этап лабораторной работы должен находиться в отдельной семантической секции `<section>`.

### LEGO 1×1

Создайте отдельную секцию с одним элементом LEGO размером 1×1. Элемент может иметь произвольный цвет. Элемент должен иметь один штырёк (stud). Элемент и отображение штырька должны быть реализованы с использованием CSS Grid.

### Полка IKEA KALLAX

Создайте секцию с образом полки IKEA KALLAX. Полка должна состоять из восьми ячеек, расположенных в два ряда и четыре столбца. В каждой ячейке разместите цветной div разного размера и цвета. Элементы должны находиться в разных положениях внутри ячеек.

### Другие элементы LEGO

Создайте дополнительные детали LEGO:

- 2×1;
- 2×2;
- 2×3;
- L-shaped 2×2.

Количество и расположение штырьков (stud) должно соответствовать форме детали. Цвет детали должен задаваться классом, а не отдельным набором CSS-правил для каждой конкретной детали. Общие свойства различных деталей необходимо вынести в общие CSS-классы.

### Тетрис из LEGO

Создайте секцию, в которой из разработанных LEGO-деталей собирается игровое поле Тетриса. Разместите на поле созданные LEGO-детали. Используйте все типы созданных деталей. Для повторения огиринальных форм в тетрисе. Детали должны образовывать состояние игрового поля во время партии в Тетрис.

### Адаптивная полка KALLAX

Создайте секцию с адаптивной полкой для LEGO-деталей. В качестве основы используйте Grid-шаблон RAM. Полка должна автоматически изменять количество столбцов в зависимости от доступной ширины, т.е. при уменьшении ширины окна элементы должны автоматически переноситься на новые строки. Количество элементов в строке не должно задаваться вручную для каждого размера экрана. Используйте repeat(), minmax(), auto-fit или auto-fill.

### Общая структура страницы

Структура страницы должна содержать: header, aside c nav, main, footer.

Содержимое header и footer скопируйте из предыдущих лабораторных работ. В aside создайте навигационное меню со ссылками на все этапы данной лабораторной работы. В main поместите все секции с заданиями этой лабораторной работы.

aside и main должны находиться рядом и образовывать основную двухколоночную структуру страницы.

Зафиксируйте результаты работы с помощью системы контроля версий git и отправьте репозиторий на GitVerse.

## Требования к коду:

1. Отсутствие ошибок на [валидаторе](https://validator.w3.org/) для html и css.
1. Код отформатирован и читаем.
2. CSS содержит минимально необходимое количество повторяющихся правил.
1. Оптимально использован grid.
